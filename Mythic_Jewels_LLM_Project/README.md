# MYTHIC JEWELS — LLM-Driven Mobile Game Project

Bu klasör, Android ve iOS için geliştirilecek **Mythic Jewels** adlı özgün, oyun içi sanal ekonomi kullanan, gerçek para bahis/kumar içermeyen, fantastik Match-3 + macera + kahraman + boss + hazine + bölüm ilerleme oyununun uçtan uca üretim kaynağıdır.

## Ana hedef
LLM/AI coding agent'ın projeyi sıfırdan okuyup **aşama aşama, test ederek, önceki onaylı işleri bozmadan** geliştirebilmesi.

## Ürün özeti
- Tür: Match-3 Puzzle / Adventure / Hero Progression
- Platform: Android + iOS
- Motor: Unity
- İlk sürüm: 50 bölüm, 1 ana dünya, 3 kahraman, 5 boss, temel canlı operasyon altyapısı
- Gerçek para bahis/kumar: YOK
- Gerçek dünya ödülü/çekilebilir para: YOK
- Monetizasyon: yalnızca oyun içi sanal içerikler + uygun reklam/IAP
- Dil: Türkçe + İngilizce başlangıç
- Tasarım: premium 2.5D fantasy casual; casino kopyası olmayan özgün kimlik

## En önemli kural
LLM önce `00_MASTER/CHIEF_PROMPT.md` dosyasını, sonra `00_MASTER/BUILD_ORDER.md` dosyasını okumalıdır. Her faz tamamlanmadan sonraki faza geçilmez. Her kabul kriteri test edilmeden iş “tamamlandı” sayılmaz.
