# PRODUCT VISION

## Ürün
Mythic Jewels, oyuncunun kristal taşları eşleştirerek kahraman güçleri oluşturduğu, fantastik dünyalarda ilerlediği ve boss'ları yendiği bir Match-3 Adventure oyunudur.

## Oyuncu vaadi
“Her hamlede bir şey tetikle, kahramanını güçlendir, haritada ilerle ve yeni mitolojik dünyaları keşfet.”

## Hedef his
- Hızlı öğrenme
- Güçlü görsel geri bildirim
- Kısa oturumlar
- Bölüm tamamlama tatmini
- Koleksiyon ve ilerleme
- Boss karşılaşmalarında dramatik an

## Kaçınılacak kimlik
- Casino arayüzü
- Bahis masası
- Gerçek para kazanma
- Cash-out
- Kumarhane dili
- Üçüncü taraf karakter kopyaları

## Core loop
Map → Level → Match → Combo → Hero Ability → Objective → Victory → Reward → Upgrade → New Level

## Meta loop
World → Hero collection → Hero upgrades → Boss progression → New worlds → Events

## Oturum hedefi
Tipik bölüm 2–5 dakika. Oyuncu başarısız olduğunda tekrar denemek için açık ve adil bir neden görmeli.

## MVP
50 level / 1 world / 3 heroes / 5 bosses / 8 tile types / 6 boosters / 3 chest tiers / daily missions / shop / rewarded ad / virtual IAP.
