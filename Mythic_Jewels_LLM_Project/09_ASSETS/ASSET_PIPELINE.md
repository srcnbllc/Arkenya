# ASSET PIPELINE

## Asset categories
Characters / Bosses / Tiles / UI / Backgrounds / VFX / Audio / Icons.

## Naming
category_subject_variant_version
Örn: hero_asterion_idle_v01

## Process
Brief → Concept → Review → Final → Optimize → Import → Device Test → Approved.

## AI-generated art
AI-generated asset kullanılıyorsa üretim kaynağı, prompt/version, insan kontrolü ve lisans durumu kaydedilir.

## Performance targets
- Texture atlasing
- Sprite compression
- Limited overdraw
- Object pooling for particles
- Addressables for large content
