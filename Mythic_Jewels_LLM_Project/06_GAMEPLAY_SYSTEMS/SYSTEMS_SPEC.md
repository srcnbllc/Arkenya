# SYSTEMS SPEC

## Hero roster — MVP

### Asterion
Role: balanced
Power: Starfall — clears a 3x3 area after meter fill.

### Nyra
Role: combo
Power: Prism Rush — converts selected tiles into special tiles.

### Thalor
Role: defensive
Power: Tide Shield — blocks next boss penalty.

These are original fictional characters.

## Boss roster
1. Stone Colossus — tutorial boss
2. Ember Wyrm — fire hazards
3. Sea Leviathan — frozen/water blockers
4. Shadow Titan — hidden tiles
5. Sky Tyrant — timed attacks

## Lock types
- Level gate
- World gate
- Hero unlock
- Feature unlock
- Event lock

Locks must always explain:
“What is locked?”, “How do I unlock it?”, “What progress is required?”

## Rewards
- Gold: upgrades/standard shop
- Gems: premium virtual currency
- XP: player progression
- Hero XP: hero progression
- Energy: level attempts
- Booster: tactical consumable

## Chest tiers
Wood → Silver → Mythic.
Chest content is virtual only. Reward probabilities are configuration-driven and testable.

## Daily missions
3 missions/day initially.
Examples:
- Complete 3 levels
- Create 5 specials
- Defeat 1 boss
