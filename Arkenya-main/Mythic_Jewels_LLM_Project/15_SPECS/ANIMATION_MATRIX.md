# ANIMATION MATRIX

## Board
Idle → Hover/Touch → Swap → Match → Special → Cascade → Combo → Settle

## Hero
Idle → Anticipation → Ability Cast → Impact → Recovery → Victory

## Boss
Idle → Telegraph → Attack → Hit → Stagger → Phase Change → Defeat

## UI
Button Idle → Press → Success/Error → Reward Reveal

Animation rules:
- gameplay-critical animations never block input unnecessarily
- skip/fast-forward where appropriate
- use pooling for repeated effects
